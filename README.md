# Mortgage Extra Payment Payoff Simulator

## 概要
借入額・金利・返済期間を入力し、毎月の追加返済額スライダーで完済期間の短縮月数と節約利息をリアルタイム更新する住宅ローン教育ツール。

## 機能
- 借入額・金利・返済期間の入力
- 追加返済額スライダー（$0〜$2,000）
- 通常返済 vs 追加返済の残高推移折れ線グラフ
- 完済期間の短縮月数・節約利息のリアルタイム表示
- 元利均等返済の自動計算

## 使い方
ローンパラメータを入力後、追加返済額スライダーを動かすと、グラフと統計がリアルタイムで更新されます。追加返済による利息節約効果を視覚的に確認できます。
